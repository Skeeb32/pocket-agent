# Security

Pocket Agent is an early single-user local application, not a hardened service. Do not expose its data directory or an unauthenticated Ollama server to the internet. Notes and tasks are stored without encryption.

If you find a vulnerability, use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, open an issue asking the maintainer for a private reporting channel without including exploit details, credentials, or private data.

Reports should describe affected versions, impact, and a minimal reproduction using synthetic data. This project does not currently promise a response-time SLA.
