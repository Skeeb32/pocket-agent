# Contributing

Open an issue describing the problem or propose a focused pull request. Include a concrete example of the resulting behavior.

Use Node.js 22 or later. Run `npm test` and `npm run demo` before submitting. Add behavioral tests for new tools, especially validation failures and denied approvals. Keep runtime dependencies minimal and document any new configuration.

Never include `.env`, personal notes, task data, credentials, or model transcripts in commits. New tools that change data or communicate externally must have explicit human approval. Describe live-model testing separately from mocked tests.
